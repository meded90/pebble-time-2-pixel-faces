# Changelog

- Add the native Steel Bands workout interface for Pebble Time 2.
- Add persistent workout timing, a ten-minute resume window, and one saved summary.

- Add heart-rate zones, a rolling 60-minute chart, and target-zone vibration.
- Add one-minute resting PPG-RMSSD with a seven-day personal baseline.
