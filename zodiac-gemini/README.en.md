# Zodiac: Gemini

[Русский](README.md) · [English](README.en.md) · [All watchfaces](../README.en.md#native-200228-previews)

[![Zodiac: Gemini](../assets/screenshots/zodiac-gemini.png)](../assets/screenshots/zodiac-gemini.png)

An illustrated Gemini watchface for Pebble Time 2 (`emery`, 200×228) with
large hours and minutes in the upper-left corner.

## Features

- full-screen 64-color artwork;
- large LECO digital time;
- system 12/24-hour preference;
- updates once per minute;
- fully offline with no settings;
- dedicated tools for preparing the background, digits, and publishing assets.

## Build and run

```bash
pebble build
pebble install --emulator emery --logs
```

Ready package: [`../dist/zodiac-gemini.pbw`](../dist/zodiac-gemini.pbw).
See [`PUBLISHING.md`](PUBLISHING.md) for publishing assets.

## Permissions

None.
