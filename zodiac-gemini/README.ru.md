[Установить из RePebble](https://apps.repebble.com/zodiac-gemini_a1c61f1227144535accbf53c).

Иллюстрированный циферблат Близнецов для Pebble Time 2 (`emery`, 200×228) с
крупными часами и минутами в левом верхнем углу.

## Возможности

- полноэкранная 64-цветная иллюстрация;
- крупные цифровые часы шрифтом LECO;
- системный формат времени 12/24 часа;
- обновление раз в минуту;
- автономная работа без настроек и сети;
- отдельные инструменты подготовки фона, цифр и материалов публикации.

## Сборка и запуск

```bash
pebble build
pebble install --emulator emery --logs
```

Релиз-кандидат: [`../dist/candidates/zodiac-gemini-1.4.0.pbw`](../dist/candidates/zodiac-gemini-1.4.0.pbw).
Материалы публикации описаны в [`PUBLISHING.md`](PUBLISHING.md).
