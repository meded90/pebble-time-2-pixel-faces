Включайте звук на своём iPhone прямо с Pebble Time 2. Откройте приложение на часах, выберите iPhone кнопками Up и Down, затем удерживайте Select 650 мс для отправки команды.

Приложение работает внутри Pebble Core на iPhone и обращается напрямую к Apple по HTTPS. Отдельное приложение-компаньон и промежуточный сервер не нужны. Настройка поддерживает двухфакторную авторизацию через доверенное устройство, несколько iPhone, автоматический выбор языка системы и понятные состояния для недоступного телефона, истёкшей сессии и ограничения частоты запросов.

Пароль и код 2FA используются только во время входа и не сохраняются. Сессионные токены Apple остаются в локальном хранилище Pebble Core на подключённом iPhone. Сохранённую сессию можно удалить на странице настроек.

Важно: это независимая неофициальная утилита, использующая недокументированный сервис Apple. Приложение не связано с Apple и не одобрено Apple. Apple может изменить сервис без предупреждения — вход или отправка звука могут временно либо окончательно перестать работать.

Требуются Pebble Time 2 (emery), Pebble Core на iPhone, интернет и Apple Account с включённой функцией «Локатор».
