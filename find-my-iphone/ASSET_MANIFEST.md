## Позиции слоёв

| Слой | Положение на экране |
|---|---:|
| Подушка + iPhone | `(24, 67)`, холст 145×99; видимый объект сохраняет прежний масштаб |
| Волны | `(140, 111)` у верхнего торца iPhone; фазы 1 → 2 → 3 → 2 |
| Badge | `(162, 10)` |

Порядок: фон → единая сцена с подушкой и телефоном → волны → скруглённые системные панели → бейдж → текст → progress bar. Телефон не меняет форму и положение между кадрами; анимируются только три волновые фазы. Прозрачность бинарная, масштабирование nearest-neighbour, каждый RGB-канал приводится к `0/85/170/255`.

`assets/states-preview-v4.png` содержит четыре точных кадра 200×228 для быстрой визуальной проверки.
